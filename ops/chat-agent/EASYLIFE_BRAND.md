# Фирменный стиль EasyLife AI — для документов ОТ НАС клиенту

Эталон — основной сайт https://easylife-main-v2.vercel.app (Unbounded + Manrope, тёмно-синий + лайм).
Этим стилем оформляются только **наши рабочие документы для клиента**: контент-стратегия, аудит, прогноз, отчёт, КП, план, разбор, презентация на созвон.
Всё, что клиент покажет **своей** аудитории (рилсы, сторис, карусели, обложки, лид-магниты, гайды, чек-листы, баннеры, страницы клиента), — **никогда** не в этом стиле, только по бренд-киту клиента. Подробно — раздел «Чей стиль» в CLAUDE.md.

## Название и логотип
В документах для клиента **нет** названия EasyLife, логотипа, наших сервисов (HeyGen, Metricool, ChatPlace, Viralmaxing и т. п.) и других клиентов. Узнаваемость — только через цвета и шрифты. В колонтитуле — только номер слайда.

## Шрифты
```html
<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&family=Unbounded:wght@600;700;800&display=swap" rel="stylesheet">
```
- **Unbounded** 700–800 — заголовки, крупные цифры, кнопки. Широкий: на слайде 1280×720 заголовок не больше 44px, letter-spacing −0.01em, до 2 строк.
- **Manrope** 400–700 — весь остальной текст, на слайде не мельче 18px, в таблицах не мельче 16px.

## Цвета
```css
:root{
  /* тёмная часть: обложка, разделители разделов, финальный слайд */
  --bg:#070526; --bg-2:#0c0938; --card:#100c3d;
  --neon:#b6f500;   /* лайм — главный акцент */
  --teal:#2ee6c8;   /* бирюза — метки над заголовками, линии */
  --vio:#6b2cff;    /* фиолет — акцент на светлом */
  --white:#f3f2ff; --muted:#7a78a3; --muted-2:#4f4d75;
  --line:rgba(182,245,0,.14); --line2:rgba(255,255,255,.07);
  /* светлая часть: все рабочие слайды с цифрами и таблицами */
  --paper:#f3f2ff; --paper-2:#e9e6fb; --ink:#0c0938; --ink-muted:#5b5880;
  --card-light:#ffffff; --border-light:#dcd7f5;

```

## Раскладка документа (слайды и скролл-страницы)
Ярослав просит, чтобы цифры легко читались: **рабочие слайды светлые, тёмные — только обложка, разделители и финал.**

**Тёмные слайды** (`--bg`):
- Фон: три мягких размытых свечения — лайм слева сверху, бирюза справа сверху, фиолет снизу (radial-gradient, прозрачность 0.15–0.25).
- Метка над заголовком: короткая бирюзовая линия 28px + текст капсом с разрядкой 0.14em, бирюза, 14px.
- Заголовок Unbounded белый, ключевое слово лаймом со свечением `text-shadow:0 0 34px rgba(182,245,0,.4)`.
- Карточки `--card`, рамка `--line`, скругление 16–20px, тень `0 30px 70px -30px rgba(0,0,0,.8)`.

**Светлые слайды** (`--paper`, чередуй с `--paper-2` для разбивки):
- Текст `--ink`, пояснения `--ink-muted`. Метка над заголовком — фиолетом `--vio`, тот же приём с линией.
- Карточки белые, рамка `--border-light`, скругление 14–16px, лёгкая тень `0 10px 30px -18px rgba(12,9,56,.25)`.
- **Лайм на светлом — только заливкой, не текстом** (лаймовый текст на светлом не читается): плашка-маркер под ключевым словом, подсветка колонки базового сценария `rgba(182,245,0,.28)`, бейдж «база». Текст на лайме — `#0b1200`.
- Крупные цифры — Unbounded `--ink` или фиолетом `--vio`.
- Таблицы: шапка `--ink` с белым текстом, строки через одну `--paper`, тонкие линии `--border-light`, выравнивание цифр по правому краю.
- Воронка — ряд плашек со стрелками и процентом на стрелке; финальная плашка (продажа/результат) — лаймовая с тёмным текстом.

**Кнопки и ссылки** (если документ кликабельный): лайм `#b6f500`, текст `#0b1200`, Unbounded 700, скругление 14px.

## Технически
- Слайды 1280×720: `@page{size:1280px 720px;margin:0}`, каждый слайд `width:1280px;height:720px;overflow:hidden;page-break-after:always;-webkit-print-color-adjust:exact;print-color-adjust:exact`. На экране — по центру друг под другом, на телефоне масштабируются (`transform:scale` по ширине).
- Скролл-страница: ширина контента до 1100px, отступы по бокам 16px на телефоне, текст 18px.
- Перед отправкой посмотри каждый слайд: `node ~/bin/html2pdf.mjs <file>.html <папка>/_shots --png` → Read картинок. Проверь: текст не вылезает, тёмный/светлый чередуются как выше, лайма-текста на светлом нет, нет слов EasyLife и наших сервисов (`grep -io 'easylife\|heygen\|metricool\|chatplace\|viralmaxing\|higgsfield'` — пусто).
